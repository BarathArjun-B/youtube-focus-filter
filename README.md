# 🎯 YouTube Focus Filter

A smart Chrome Extension that helps users stay productive on YouTube by intelligently blurring distracting entertainment content while keeping educational and productive videos visible.

---

## 🚀 Features

* 🎵 Blur songs and music videos
* ⚽ Blur football entertainment content
* 🎮 Blur gaming and meme content
* 📚 Keep tutorials and coding videos visible
* 🤖 Smart category-based filtering
* ⚡ Real-time YouTube content analysis
* 🎨 Smooth blur overlay UI
* 🔧 Custom keyword filtering
* 🧠 Productive content protection logic

---

## 🧠 How It Works

The extension analyzes:

* Video titles
* Channel names
* Metadata keywords

Then categorizes videos into:

* Music
* Football entertainment
* Gaming
* Memes
* Movies & cinema
* Shorts/Reels
* Educational/Productive

Distracting content is automatically blurred while productive content remains visible.

## 📦 Installation

### 1. Clone the repository

```bash
git clone https://github.com/BarathArjun-B/youtube-focus-filter.git
```

### 2. Open Chrome Extensions

```text
chrome://extensions/
```

### 3. Enable Developer Mode

Turn on **Developer Mode** from the top-right corner.

### 4. Load the Extension

Click:

```text
Load Unpacked
```

Then select the project folder.

---

## ▶️ Usage

1. Open YouTube
2. Browse normally
3. Distracting entertainment videos will automatically blur
4. Educational and productive videos remain visible
5. Click “Reveal Anyway” to temporarily view blurred content
